- _sistemt org - centralna metodološka perspektiva razvojno-proizvodne firme_
	- centralni kut gledanja: potreba/politika -> strategija -> operativa -> taktika -> teren. Svi drugi Pogledi se međusobno referiraju kroz ovu centralnu Perspektivu.
- _sistemt org - arhitektura i operativa razvojno-proizvodne firme_
- _sistemt net - digitalna infrastruktura razvojno-proizvodne firme_
- _sistemt pogon - infrastruktura i operativa proizvodnog pogona_

- trilogia t<sup>3</sup>r
- trilogija terce tihe terenske revolucije
- _trilogia de via tertia o'eklesia arma_

1. **Praksis** - osnove ekonomije
2. **Firma** - digitalno-operativna kičma razvojno-proizvodne firme

	čovik/obitelj (_principia_) -> ekipe/firme/mista (_kodeks_) -> šahovnica (_methodos_)
